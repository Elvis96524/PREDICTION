# 4D 玄学推演

按干支五行、梅花易数和二十八星宿,把日期和时辰换算成四位数字。
这是一个网页应用(PWA),上传到 GitHub Pages 后,iPhone、Android 和电脑都可以直接打开或"安装"到主屏幕,不需要应用商店。

> 声明:4D 开奖是随机事件,每组号码的中奖概率都相同。本工具只是干支、八卦与星宿的趣味换算,不构成任何投注建议。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `index.html` | 应用本体(页面、样式、推演逻辑都在这一个文件里) |
| `manifest.webmanifest` | 让手机识别为可安装应用(名称、图标、颜色) |
| `sw.js` | 离线缓存,装好后没有网络也能打开 |
| `icon-192.png`、`icon-512.png`、`apple-touch-icon.png` | 应用图标(安卓用前两个,iPhone 用第三个) |
| `4d_predictor.py` | 命令行版本(可选,电脑上用 Python 3 运行) |

## 一、上传到 GitHub 并开启网页托管

1. 在 GitHub 新建一个仓库(例如 `4d-predictor`),可以设为公开。
2. 把下载到的所有文件上传到仓库根目录,不需要建任何文件夹。
   网页上传时点 **Add file → Upload files**,把全部文件一起拖进去,再点 **Commit changes**。
3. 进入仓库的 **Settings → Pages**。
4. **Build and deployment** 里 Source 选 **Deploy from a branch**,Branch 选 `main`,文件夹选 `/ (root)`,点 **Save**。
5. 等一两分钟,页面顶部会显示网址,形如 `https://你的用户名.github.io/4d-predictor/`。

## 二、安装到手机

先用手机浏览器打开上面的网址。

**iPhone / iPad(必须用 Safari)**
1. 点底部的分享按钮。
2. 选 **添加到主屏幕**。
3. 点 **添加**,主屏幕上就有图标了。

**Android(Chrome)**
1. 点右上角菜单(三个点)。
2. 选 **安装应用** 或 **添加到主屏幕**。
3. 确认后图标会出现在桌面或应用列表里。

**电脑(Chrome / Edge)**:地址栏右侧有安装图标,点一下即可。

装好后从主屏幕打开,会像普通应用一样全屏显示。第一次打开需要联网,之后可以离线使用。

## 三、常见问题

- **网址打不开**:Pages 刚开启时要等几分钟;也检查 Branch 是不是选对了。
- **汉字字体和预览不一样**:页面从 Google 字体加载思源宋体和黑体。第一次联网后会被缓存,没网时自动换成手机自带的中文字体,功能不受影响。
- **更新了文件但手机还是旧版**:把 `sw.js` 第一行附近的 `VERSION` 从 `v1` 改成 `v2`,再提交即可。
- **想做成 APK 或上架应用商店**:需要另外用 Capacitor 或 PWABuilder 打包,安卓还要自己签名,iOS 需要苹果开发者账号。一般用上面的"安装到主屏幕"就够了。

## 四、命令行版本(可选)

```bash
python 4d_predictor.py                      # 今天、当前小时
python 4d_predictor.py -d 2026-10-12 -H 15  # 指定日期和小时
python 4d_predictor.py -n 5                 # 输出 5 组
```

注意:命令行版和网页版使用不同的随机数生成器,同一天给出的号码不会相同。两者的干支、卦象和星宿结果一致。

## 说明

起卦以公历月日代替农历,节气按固定日期近似,交节前后一天可能与万年历有出入。二十八星宿的吉凶表采用通行的一种口诀,如与你熟悉的万年历不同,可在页面"高级:星宿校准"里调整偏移值。
